Upload a release

Draft first

Upload a signed APK for org.imdtv.iptvtv.managed. Maximum 100 MiB on Pages.

The Pages upload validator checks ZIP structure and required signing artifacts and calculates SHA-256. It does not cryptographically verify the signature or parse Android binary manifest version metadata. Android must verify the package, version, hash and matching signing certificate before installation.
APK contents and version codes are immutable.

CONNECTION CONFIGURATION

Provider servers

Maintain the trusted server list available in the app.

Revision —
These servers receive customer provider credentials. Only add HTTPS origins you own or explicitly trust. Changing this list is a security-sensitive action. Customers choose a server manually and re-enter their login; the app must not automatically fail over to another server.

Trusted servers

1–10 entries. URLs must be HTTPS origins, with no credentials, path, query or fragment. Server IDs remain stable across edits.

All changes are saved together.
